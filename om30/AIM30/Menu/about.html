Application Implementation Method, Release 3.0.0
The Application Implementation Method (AIM) 3.0.0 release provides a method pack for AIM and Add-In packages for FastForward Financials 2.0 and Project Management Method (PJM) 2.6.1.

Application Implementation Method release 3.0.0 includes:

  • AIM Method Handbook, 3.0.0
  • AIM Process and Task Reference, volume 1, 3.0.0
  • AIM Process and Task Reference, volume 2, 3.0.0
  • AIM Process and Task Reference, volume 3, 3.0.0
  • AIM Deliverable Templates, 3.0.0
  • AIM FastForward Add-In Handbook, 2.0.0
  • AIM FastForward Deliverable Templates, 2.0.0
  • PJM Method Handbook, 2.6.0
  • PJM Process and Task Reference, 2.6.0

 
Software Requirements

  • Microsoft Office 95 or Office 97
  • Microsoft Project 4.0, MS Project 98 or ABT Project Workbench 4.0 or later

  • 32 MB RAM (64 recommended)
 
De-Installation
To remove the installation of AIM 3.0.0, select the "Uninstall AIM 3.0" icon from the "Oracle Method AIM 3.0" program group.

Once you start the Uninstall procedure, you can choose whether you would like to partially de-install or fully de-install. A partial de-install will remove the AIM 3.0 foundation files only. It will not de-install any associated add-ins that you have installed separately. This is useful when you want to re-fresh your installation without having to re-install all of your add-ins.

If you choose to fully de-install, AIM 3.0 and all associated add-ins will be completely removed. You should let the de-install procedure run until finished. It cannot be run again if aborted.

 
Known Problems
The following is a list of known problems you may encounter when using this method. Additionally, you can check for patches and updates to your existing installation of AIM by clicking the "Check for Add-ins and Updates" button from the Add-In Selection page.

  1. MICROSOFT WORD DELIVERABLE TEMPLATE READ-ONLY WARNINGS

    The Microsoft Word deliverable templates are read-only format to prevent you from accidentally making changes to the base deliverable template files. Use the File...Save As command to save a copy of the deliverable template with a name of your choice to a directory of your choice.

    If you choose to Save the Microsoft Word deliverable template rather than Save As, you will see a Microsoft read-only warning. This warning is for your protection. Please select OK and the Save As dialog box appears. Navigate to a directory of your choice and type in a filename of your choice.

  2. NETSCAPE USERS MAY NEED TO MODIFY THEIR PREFERENCES

    While using the AIM 3.0 method pack, if you should encounter a Netscape message, asking you whether you want to open a file or save the file to disk, you should select "Open it", and de-select the "ask me before opening.." checkbox. Any helper applications which are opened from the method pack are not being opened by your browser. They are actually being launched by an Oracle Method system file, which expects to be executed. Choosing to save an Oracle Method system file instead of opening (executing) can produce some undesired results or errors.

  3. NOTES APPEAR FOR A SHORT PERIOD OF TIME

    Each page containing a list of deliverable templates has a Notes column. When you place your cursor over the note icon, a short message appears and then, after approximately 3 seconds, disappears. If you are unable to read the message in the allotted time, move your courser off the note icon and then back onto the note icon.

  4. BLANK BUTTONS MAY APPEAR ON THE WINDOWS TASK BAR

    Occasionally, under normal operations, Windows 95 will leave blank buttons on the Task Bar. These buttons can be removed by clicking on them.

  5. MOVING THE MASS CHANGES DIALOG BOX RESULTS IN BLANKED OUT SCREEN

    If you use the Mass Changes function available for deliverable templates associated with Microsoft Word, please be aware that moving the Mass Changes dialog box to another location on the screen will result in blanking out of the uncovered portions of the screen. You will not be able to view the document. To view the document press the Cancel button in the Mass Changes dialog box.

  6. SELECTING MORE THAN ONE DELIVERABLE TEMPLATE ASSOCIATED WITH MICROSOFT WORD MAY CAUSE MULTIPLE INSTANCES OF MICROSOFT WORD TO LAUNCH

    When you select more than one deliverable template associated with Microsoft Word, multiple instances of Microsoft Word may launch. You can change your preferences to launch one instance of Microsoft Word by performing the following steps:

    1. Go to Start > Programs > Windows Explorer.
    2. In Explorer, select View > Folder Options.
    3. In Folder Options, select the File Types tab.
    4. Scroll to and select Microsoft Word Document.
    5. Choose the Edit button.
    6. In the Edit File Type dialog box, under the Action heading, double-click on open.
    7. In the Editing Action for Type dialog box,
      Check Use DDE.
      For the DDE Message, type [FileOpen("%1")].
      For the Application, type WinWord.
      For the Topic, type System.
    8. Choose OK.
    9. Choose Close.

  7. INSTALLING AN OLDER VERSION OF A METHOD PACK

    All method packs have shared (global) files. All method packs installed on the same machine should be installed to the same drive. Otherwise, shared files could be invalidated, causing templates not to launch.

  8. ACTIVATING/DE-ACTIVATING CRITERIA BARS

    Please note that the pop-up information displayed when hovering your cursor over the bottom portion of a criteria bar will display information for the criteria bar to the right of the bar your cursor is hovering over. This is because the area coordinates for the pop-up information does not line up exactly with the criteria bars because they are diagonal. You will need to mouse-over the top portion of the criteria bar to see the correct information displayed in the pop-up window, and also to activate/de-activate the criteria bar.

    Please see the "TIPS FOR BETTER PERFORMANCE" section if you are experiencing slow performance when activating/de-activating the criteria bars.

  9. DEFAULT REPLACEMENT VARIABLES

    The values used for Word deliverable template default variables must be set for each method pack or add-in. If you are using a deliverable template from one method pack or add-in, you will not be able to see the default values that you set for another method or add-in.

  10. VIEWING CONTEXT-SENSITIVE TASK/PROCESS INFORMATION IN ADOBE ACROBAT READER

    The "Task Guidelines" and "Process Guidelines" Icons are used to provide context sensitive task or process information, depending upon which task or process you have navigated to within the AIM 3.0 interface. This context-sensitive information is supported only for Netscape users who have Adobe Acrobat Reader installed as a plug-in. For Internet Explorer users, or Netscape users who have Adobe Acrobat installed as a helper application, these links will open the Acrobat file to the first page.

  11. POP-UP INFORMATION DISPLAYED IN THE DIAGRAM OF THE MAIN AIM 3.0 PAGE

    Pop-up information is not consistently displayed when moving your cursor over various different process and phase intersections within the diagram on the main page. However, all of the intersections are "hot," and they should take you to the desired task listing page when you click on them.

  12. NAVIGATING WHILE AIM 3.0 IS DISPLAYING ALL TASKS

    When you click on the "Show All Tasks" button, it may take a few minutes for all task information to be generated and displayed. While the information is being generated, please avoid navigating back to the Main page until the operation has completed. Doing so may cause AIM 3.0 to produce an "Illegal Operation" error message and will then close the application.

  13. CHANGING THE PRIORITY OF AN ADD-IN

    After you have installed and activated an Add-in, click the "OK" button from the Add-In page before changing the priority. Clicking "OK" will take you back to the Main page, and you will then need to click the "Add-Ins" link to go back to the Add-In page. This may take a little longer, but it will prevent AIM from producing an Illegal Operation error which will force AIM to close.
