Aplikasi APEX Siap-Install

Aplikasi yang terdaftar di custom_apps.json bisa dipasang langsung lewat Custom App Gallery APEX. Aplikasi lain tersedia sebagai export .sql / .zip.

Pasang lewat App Gallery

Di APEX Workspace → App Gallery → tambahkan URL berikut sebagai custom gallery:

https://raw.githubusercontent.com/iwanhe/pandawa/main/custom_apps.json
