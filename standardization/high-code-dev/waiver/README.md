# Waiver (Pengecualian Sementara)

Waiver adalah izin tertulis untuk tidak mematuhi aturan WAJIB atau DILARANG dalam waktu terbatas.

## Aturan

- Setiap waiver wajib punya **tanggal remediasi** dan **pemilik**.
- Dibuat dari [template waiver](../templates/template-waiver.md), nama file `WVR-NNN-<ringkasan>.md`.
- Disetujui Development Manager; untuk aturan keamanan juga oleh Security Officer.
- Register di bawah ditinjau setiap kuartal. Waiver yang lewat tanggal remediasi dilaporkan.
- Waiver bukan kegagalan. Waiver yang beralasan adalah cara sah memakai standar.
