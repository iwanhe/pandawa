# Modul Belajar Next.js untuk Developer Junior

Sepuluh modul berurutan untuk developer yang baru mengenal Next.js. Setiap modul berisi tujuan, konsep, contoh, latihan, cek pemahaman, dan ID aturan standar yang terkait.

Contoh di modul mengacu ke aplikasi contoh di [`../examples/benar-app`](../examples/benar-app/) dan ditulis untuk **Next.js 16.4 (App Router, Cache Components)**.

| Modul | Topik | Durasi |
|---|---|---|
| [01](01-dasar-react-typescript.md) | Dasar React dan TypeScript yang dibutuhkan | ± 3 jam |
| [02](02-membuat-proyek-dan-struktur.md) | Membuat proyek dan struktur App Router | ± 2 jam |
| [03](03-halaman-layout-navigasi.md) | Halaman, layout, dan navigasi | ± 2 jam |
| [04](04-server-dan-client-components.md) | Server Components dan Client Components | ± 3 jam |
| [05](05-mengambil-data-dan-caching.md) | Mengambil data dan caching | ± 3 jam |
| [06](06-form-dan-server-actions.md) | Form dan Server Actions | ± 3 jam |
| [07](07-loading-error-not-found.md) | Loading, error, dan not found | ± 2 jam |
| [08](08-autentikasi-dan-otorisasi.md) | Autentikasi dan otorisasi | ± 3 jam |
| [09](09-gambar-font-performa.md) | Gambar, font, dan performa | ± 2 jam |
| [10](10-testing-dan-deployment.md) | Testing dan deployment | ± 3 jam |

**Total:** ± 26 jam, dapat dijalankan dalam dua minggu (± 3 jam per hari kerja).

## Cara memakai
1. Kerjakan berurutan; setiap modul memakai hasil modul sebelumnya.
2. Kerjakan latihan di proyek latihan sendiri, bukan di repo aplikasi produksi.
3. Setelah setiap modul, jalankan `npm run typecheck && npm run lint && npm run build`.
4. Diskusikan jawaban "Cek pemahaman" dengan mentor.
